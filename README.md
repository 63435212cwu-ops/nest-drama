# NEST-DRAMA 群像引擎

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)

**中文** ｜ [English](README_EN.md)

NEST-DRAMA 是一款单元剧情创作引擎。它以单元故事、单元剧情为基本单位，以卷集剧情为编排骨架，用于辅助长篇、中篇小说的创作，也适合直接创作短篇故事——先为作品建立一个世界，再让角色在其中自主行动、推动情节。

## 定位与用法

NEST-DRAMA 的产出路径不是「一键生成整部长篇小说」。它的基本产出单位是剧情单元：先创作单元故事、单元剧情，再由卷集剧情将它们编排成更大的叙事骨架，用以辅助长篇、中篇小说的推进。

它也适合直接创作短篇故事。创作时，先为一个作品建立一个独立的世界，再让角色在世界内自主行动、推进情节、兑现因果。

两种组织方式——

- **单故事**：一个故事、一个或几个单元，演完即收口
- **卷集故事**：多个单元一卷接一卷推进，角色的状态、旧账、关系跨单元延续

## 运作流程

**第一步 · 构建世界。** 提供设定材料（纯文本）。引擎读取全部材料后：确立世界观；沉淀一份仅引擎自身掌握的「真相底稿」；为每位出场人物建立三份档案——人物内核（我是谁）、语言声纹（如何说话）、当前心象（此刻装着什么）；随后将故事切分为单元，每个单元带独立目标与轮次预算。

**第二步 · 逐单元推演。** 每一轮如同一场戏的编排：场记搭建场景并确定出场角色；轮到出场的角色按其本意说话行事，其余角色作出反应。推演稿由「监修官」审校，对表述生硬、内容重复、越界描写心理的稿子判定退回重写。裁判逐轮记录目标进度、出场冷热与是否原地空转。

**第三步 · 作者调度。** 推演过程中可随时介入（见下文「干预选项」）。单元收口后自动进入下一单元，亦可暂停以访谈角色或导出全部推演实录。

## 角色可信度的来源

- **角色只掌握阈值内的信息**：角色无法获知他人的心理与谋划，信息差真实存在——只有其应知的，才能影响其行为
- **角色承载与主线无关的个人牵挂**：每个角色生活中都悬着若干与主线无关的小事——半日的胃痛、未回复的消息、念着的人。关键时刻，这些会与主线争夺他的注意
- **剧情以世界内的自然手段推进**：故事节点通过把消息递到该知者耳中、把压力摆上台面等手段实现，不伪造事实、不改写人心

## 星系图谱

引擎每完成一次落盘，都会同步将世界绘制成一张「活图谱」——左侧面板呈现的星系图谱并非静态示意，而是随剧情生长的星图：

- **节点对应世界实体**：世界观与剧情脊椎、每个单元、每条世界书词条均生成对应节点；角色在某单元出场即生成一条「出场」连线
- **按单元着色，进度一目了然**：节点与连线按单元分色，可据此判断当前推演所及的卷集，以及角色在各单元的出场情况
- **两种视图**：星丛（3D）以可旋转的立体星群呈现图谱；关系矩阵则将角色之间的关联铺展为矩阵，便于梳理人物关系
- **始终为最新状态**：构建世界、切换单元或续演时连线实时增删，断线重连会自动补齐，所见即当前状态

## 干预选项

| 选项 | 说明 |
|---|---|
| 引力档（放养 / 适中 / 贴线） | 世界将剧情拉向目标的作用力度 |
| 上帝注入 | 向某一轮注入一句剧情指令，用后即弃 |
| 暂停 | 随时中止自动推演 |
| 访谈角色 | 在戏内询问角色，或在追问下吐露真相 |
| 续演 / 导出 | 单元收口后续演，或将全部推演实录导出 |

## 快速开始

1. 安装 Python 3（无需其他依赖）
2. 运行 `python3 ui/serve.py`，在浏览器打开 `http://localhost:8787`
3. 在控制台填入你的大模型 API 密钥 → 导入创作材料 → 点击「建世界」

**材料准备**：直接提供已有素材即可——世界观、人物设定、大纲、前置情节，纯文本即可。每个世界使用独立的一套材料；将不同作品混入同一世界会产生内容干扰。

**中断恢复**：无需从头开始。重新提交指令即可从断点继续；未被修改的材料不会重复计费。

## 数据与隐私

- 投入的材料与生成的推演内容全部保存在本地目录内，不经过任何服务器
- API 密钥存储于用户主目录（`~/.nest-drama/`），不进入项目目录，亦不纳入版本控制
- 引擎代码与创作数据完全分离：即便将本项目完整转发给他人，也无法带走你的稿件

## 技术说明

- 引擎核心 `ui/serve.py`：基于纯 Python 标准库，零第三方依赖；语言层 `ui/dupian.py`：零 token 的机械化的「AI 腔」检测
- 集成测试 `python3 ui/test_serve.py`：覆盖全链路与失败路径，使用模拟 LLM，无实际调用成本
- 发布打包 `python3 pack-release.py`：引擎与用户数据硬分离，打包后自动执行隐私审查
