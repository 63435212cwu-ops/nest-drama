# NEST-DRAMA 群像引擎

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)

**中文** ｜ [English](README_EN.md)

把小说角色变成「活人」：每个角色是一个独立模拟体——只知道他该知道的，怕他该怕的，说他自己的话。剧情线是引力场，不是铁轨：角色自由行动，世界只用「世界内的手段」把故事拉向既定节点。

## 先说清楚：它是什么，不是什么

它**不是**「一键生成一整部长篇小说」的工具。

它是**单元推演引擎**：把你的故事拆成一个个单元，一个单元一个单元往下演，每个单元演到收口为止。两种用法都行——

- **单故事**：一个故事、一个或几个单元，演完收口
- **卷集故事**：像剧集连播，多个单元一卷接一卷推进，角色的状态、旧账、关系跨单元延续

## 它是怎么「演」的

**第一步 · 搭世界。** 把设定材料（txt 文本）扔进去，引擎读完所有材料后：定下世界观；埋一份只有引擎自己知道的「真相底稿」；给每个出场人物建三张档案——他是谁（内核）、他怎么说话（声纹）、他心里此刻装着什么（心象）；最后把故事切成单元，每个单元有自己的目标和轮数预算。

**第二步 · 一个单元一个单元地演。** 每一轮像剧组开机：场记搭台，决定这一场谁上场；轮到的人按他自己的打算说话做事，在场其他人做反应。写完有位「监修官」过稿——不像人话、来回车轱辘、心理描写越界的，直接毙掉重写。裁判每轮记账：目标推进到哪了、谁好久没戏份、有没有人原地绕圈。

**第三步 · 你当导演。** 演的过程中你随时可以插手（见下一节）。一个单元收口后自动接棒下一单元，也可以停下来访谈角色、导出实录。

## 为什么演出来的人像「活人」

- **每个人只知道他该知道的**：角色看不到别人的心理和密谋，信息差真实存在——他知道的事，才进他的戏
- **角色带着私心杂念**：每个人都有几件和主线无关的小事悬在生活里——胃疼一上午、没回的消息、惦记的人。关键时刻，这些会和主线抢他
- **剧情不硬掰**：故事节点靠「世界内的手段」达成——把某人该知道的消息送到他耳边、把压力摆上台面。不造假、不改人心

## 你能插手的地方

| 你能做 | 干什么用 |
|---|---|
| 引力档（放养 / 适中 / 贴线） | 决定世界把故事往目标拉的力度 |
| 上帝注入 | 给某一轮塞一句剧情指令，用完即焚 |
| 暂停 | 随时叫停自动推演 |
| 访谈角色 | 戏内问话，或逼他说真话 |
| 续演 / 导出 | 单元收口后接着演，或把全部推演实录导出成文 |

## 怎么开始

1. 电脑上装好 Python 3（其他什么都不用装）
2. 运行 `python3 ui/serve.py`，浏览器打开 `http://localhost:8787`
3. 在控制台填你自己的大模型 API 密钥 → 把材料拖进去 → 点「建世界」

**材料怎么准备**：把手头已有的东西扔进去就行——世界观、人物小传、大纲、前情，纯文本即可。一个世界用一套材料，几本书混在一起会「串味」。

**中途断了怎么办**：不用重头再来。重新提交指令会接着跑；材料没变的部分不会重新花钱。

## 你的东西存在哪，安全吗

- 你投的材料、演出来的所有内容，全部存在**你自己电脑的这个文件夹里**，不经过任何服务器
- API 密钥存在你电脑的用户主目录（`~/.nest-drama/`），不进项目文件夹、不进版本库
- 引擎代码和你的创作数据完全分离：把这个项目原样发给别人，**带不走你的稿子**

## 给技术党（可以不看）

- 引擎本体 `ui/serve.py`：纯 Python 标准库，零第三方依赖；语言层 `ui/dupian.py`：零 token 的「AI 腔」机械检测
- 集成测试 `python3 ui/test_serve.py`：全链路 + 失败路径，mock LLM 不花一分钱
- 发布打包 `python3 pack-release.py`：引擎与用户数据硬分离，打包后自动隐私终检
