# NEST-DRAMA

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)](https://www.gnu.org/licenses/agpl-3.0)

[English](README.md) ｜ **中文**

单元剧情创作引擎：先为作品建立一个世界，再让独立角色在世界内自主行动、推动剧情，产出单元故事、单元剧情与卷集剧情，用于辅助长篇、中篇创作，也可直接创作短篇。完全本地运行，零第三方依赖。

## 特性

- **单元化创作**——以单元故事 / 单元剧情 / 卷集剧情组织叙事；辅助长中篇小说，也可直接写短篇
- **角色独立**——每个角色只掌握其应知的信息，按自身性格说话行事
- **世界驱动**——剧情节点通过世界内的因果自然达成，不强行另行安排
- **实时星系图谱**——世界以太阳系式的 3D 节点图随剧情生长；性格墙点角色即锁定其星球，双击星球可潜入该角色专属星系
- **作者可控**——引力档、上帝注入、暂停、访谈角色、续演 / 导出等干预手段
- **电影级画质**——星丛内置可调后期：ACES / AgX / Neutral 影调、曝光、辉光、颗粒、暗角、色差、变形镜头光斑、四种色调风格；程序化星云背景（fbm 银河带 + 暗尘）与近景星尘层；宽银幕影院模式带字幕条，一键导出 PNG；离屏与后台自动暂停渲染，帧率不足自动降采样
- **极简奢华预设**——一键切到鎏金影调（高光偏金、阴影沉入深蓝）、AgX、低辉光、连线减淡、彗尾缩短、静默名牌（无戏份角色的名牌只在悬停/选中时浮现）、呼吸镜头（无交互时 FOV 极慢起伏）、全屏金色发丝内框；彗尾角跨度与连线浓度可单独调
- **跃迁动画**——进出角色星系、切换单元、复位镜头时触发径向拖影 + 曝光闪 + FOV 推拉 + 标题卡；选中星球有轻脉冲
- **数目账（零 token）**——正文里说出口的数量（五千二百领重铠、存粮一千二百石…）自动入账并注入下一轮所有角色；新稿悄悄换数即判毙重推，角色明着质疑/改口则放行并记为改口
- **执法力度归一**——机检"密集毙"按篇幅归一（≥10 处，或 ≥5 处且 ≥4/千字），短稿不漏、长稿不枉杀；病谱 v4 新增欲言又止、拟人沉默、含糊指代、一字一顿、时间虚化、回忆触发器，统计层新增破折号/省略号成瘾告警
- **日/夜双主题**——纸面日间与影院夜间，可跟随系统；全站快捷键、卡司即时检索、成稿提醒、页签标题随剧情更新
- **本地优先**——纯 Python 标准库、零第三方依赖，数据与 API 密钥仅存于本机

## 安装

运行环境：Python 3（无需其他依赖）。

```bash
# 拉取仓库或解压发布包后，直接运行：
python3 ui/serve.py
```

## 使用

1. 启动引擎：`python3 ui/serve.py`
2. 浏览器打开 `http://localhost:8787`
3. 在控制台填入你的大模型 API 密钥 → 导入创作材料 → 点击「建世界」

**材料准备**：直接提供已有素材即可——世界观、人物设定、大纲、前置情节。每个世界使用独立的一套材料，勿将多部作品混入同一世界。

**支持格式**（零依赖，全部标准库解析；`GET /api/formats` 可查）：

| 格式 | 说明 |
|---|---|
| `.txt .md .csv .json .yaml .log .srt` | 纯文本；自动嗅探 UTF-8(BOM) / UTF-16 / UTF-32 / GB18030 / Big5（按"像不像人写的字"打分选编码） |
| `.docx` `.odt` | 段落、换行、制表、表格单元格 |
| `.epub` | 按 OPF 书脊顺序抽正文 |
| `.html .htm .xhtml` | 去 script/style 与标签 |
| `.rtf` | 解 GBK / Unicode 转义 |
| `.zip` | 递归展开其中所有受支持文件，跳过 `__MACOSX`，同名自动去重 |
| `.pdf` | 尽力抽取（文本型、非 CID 字体）；抽不出可读文字会明确报错并建议转 .txt/.docx |
| `.doc` | 不支持，请另存为 .docx |

单文件上限 64 MB，单次请求 512 MB；全部投放文件都读不出文字时返回 422 并附格式清单。

**中断恢复**：重新提交指令即可从断点继续，未被修改的材料不会重复计费。

## 界面与快捷键

顶栏右侧可切换主题（◐ 跟随系统 / ☀ 日间 / ☾ 夜间）与查看快捷键（?）。星丛右上角「◈ 画质」打开电影级后期面板，所有偏好保存在浏览器本机。

| 键 | 作用 | 键 | 作用 |
|---|---|---|---|
| `1`–`4` | 切换 世界 / 配置 / 推演 / 报告 | `F` | 星丛全屏 |
| `C` | 影院模式（宽银幕、隐去 HUD） | `Space` | 公转 暂停 / 继续 |
| `R` | 镜头复位 | `U` | 切换单元星系 |
| `Enter` | 进入所选角色星系 | `⌫` | 返回星丛 |
| `G` | 画质面板 | `S` | 导出星丛 PNG |
| `/` | 聚焦卡司检索 | `T` | 切换主题 |
| `H` | 历史局 | `Esc` | 逐层退出 |

## API

本地 REST + SSE，`GET /api/schema` 返回机读端点清单，`GET /api/health` 返回版本、模型接入、推演状态与账本规模。所有 JSON 响应统一带 `ok` / `success` 同义布尔，失败必含 `error`；响应头带 `X-NEST-Version`。版本号单一来源为 `ui/serve.py` 的 `VERSION`，发布包名与 health 同步。

## 数据与隐私

- 投入的材料与生成的推演内容全部保存在本地目录内，不经过任何服务器
- API 密钥存储于用户主目录 `~/.nest-drama/`，不进项目目录、不纳入版本控制
- 引擎代码与创作数据完全分离；将本项目转发给他人不会带走你的稿件
